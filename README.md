# فقط «سلام» ننویس! 🚫👋

یک صفحه‌ی تک‌فایلیِ فارسی/انگلیسی، بازنویسیِ ایده‌ی معروف [nohello.net](https://nohello.net):
به‌جای فرستادنِ «سلام» تنها و منتظر جواب موندن، سلام رو با اصلِ مطلب یکجا بفرست.

> A bilingual (Persian/English) rewrite of the [nohello.net](https://nohello.net) idea —
> send your greeting together with your actual question, not as a separate message.

## امکانات

- محتوای کامل به **فارسی (راست‌به‌چپ)** و **انگلیسی (چپ‌به‌راست)** با یک دکمه‌ی تعویض زبان
- حالت **روشن/تاریک** با تشخیص خودکارِ ترجیح سیستم و امکان تغییر دستی
- ۴ سناریوی نمونه (چت کاری، ایمیل، تیکت پشتیبانی، پیام به همکار) در قالب تب‌های قابل‌دسترس (الگوی ARIA tabs + ناوبری با کیبورد)
- انیمیشنِ ورود پیام‌ها و نشانگرِ «در حال تایپ» قبل از نمایش پاسخ (با احترام به `prefers-reduced-motion`)
- بخشِ سؤالات پرتکرار (آکاردئونِ `<details>`)
- دکمه‌ی کپیِ لینکِ صفحه
- تگ‌های Open Graph / Twitter Card و تصویرِ اشتراک‌گذاری (`assets/og-image.png`) برای پیش‌نمایشِ قشنگ هنگام فرستادنِ لینک
- بدون هیچ ابزار ساخت (build tool) یا وابستگیِ نصبی؛ فقط یک فایل HTML

## اجرای محلی

هیچ نصبی لازم نیست، کافیه فایل `index.html` رو مستقیم توی مرورگر باز کنی، یا:

```bash
python3 -m http.server 8000
# سپس در مرورگر: http://localhost:8000
```

## انتشار روی GitHub Pages

1. از تنظیماتِ ریپازیتوری، بخشِ **Pages** رو باز کن.
2. Source رو روی شاخه‌ی موردنظر (مثلاً `main`) و پوشه‌ی `/ (root)` بذار.

صفحه روی آدرسِ [orvom.github.io/NoHello](https://orvom.github.io/NoHello/) منتشر می‌شه؛ تگ‌های Open Graph از قبل با همین آدرس تنظیم شدن.

## ساختار فایل‌ها

```
index.html          صفحه‌ی اصلی (فارسی + انگلیسی)
assets/og-image.png  تصویر پیش‌نمایش برای شبکه‌های اجتماعی
```
